# 决策演练 SOP（从「数据」到「落纪律」的完整闭环）

> 定位：把一只标的的投研数据，逼成一条「能执行、能复盘、能迭代」的**本人决策**。
> 这是 fqf 产品的**灵魂**——数据是客观工具，决策演练才是让数据「帮我做决策」的那一步。
>
> 铁律：演练产出的是**本人主观判断**（定位/动作/心理价位），只进 `journal/`（已 gitignore），
> **绝不进公开报告**。AI 扮演的角色是「追问者」，不是「替你做决定的人」。

---

## 一、为什么需要这套模板

2026-09-03 的神华演练证明了一个事实：

> 用户嘴上说「等回调」，账户里却早就在 6% 收租——**自我认知与实际状态严重脱节**。
> 如果不是靠「主动要账户截图 + 逼问矛盾」，这个脱节会一直蒙着。

所以决策演练的价值不在「得出结论」，而在**逼出结论里自相矛盾的地方**，
让用户面对真实的自己，而不是面对一个模糊的念头。

---

## 二、演练五步法（核心骨架）

### 第 1 步：三问定调（让用户开口，而不是问「你怎么看」）

用户往往「不知道从何说起」，所以要**主动喂结构化问题**。固定三问：

1. **定位**：这只标的在你哪个账户、扮演什么角色？（高股息攒息 / 主动投研 / 指数底仓）
2. **动作**：现在有没有持仓？想买 / 想卖 / 观望？
3. **心理价位**：什么条件下你会动手？要**量化**（估值分位 / 股息率 / 绝对价），不许「等回调」这种模糊话。

> ⚠️ 潇姐原话：「你真好，就需要你多逼逼我，明确告诉我要回答哪些问题，
> 不然我自己不知道从何说起。」——这一步是整个演练能不能启动的前提。

### 第 2 步：逼问矛盾（戳决策线里的自相矛盾处）

拿到三问答案后，AI 要主动找「这条决策线哪里站不住」。高频矛盾点（已实战验证）：

| 矛盾类型 | 例子（神华实战） | 逼问话术 |
|---------|----------------|---------|
| **锚点等价性** | 「PE 40% 分位 + 股息率 6%」其实是同一个价（股息率≈分红比例÷PE） | 「你这两个条件，会不会是同一件事的两种说法？」 |
| **隐藏变量** | 锚股息率，但没意识到「每股分红绝对额」才是真正的锚（分红比例会变） | 「你锚的指标，背后哪个变量一变就失效？」 |
| **机会成本** | 等回调三年不回调，钱空转 = 错过别的达标标的 | 「你不买的这段时间，钱在干嘛？损失了什么？」 |
| **口径漏洞** | 「6% 股息率」没区分税前/税后（港股通扣 20%） | 「你算的数和到手的数，一样吗？」 |
| **自我认知脱节** | 以为「空仓等回调」，实际早就在收租 | 「你要不要看一下真实账户，再重新回答一次？」 |

### 第 3 步：真实数据复核（关键：主动要账户截图）

**不要只听口头描述。** 用户对自己账户的认知经常是错的。主动要求：

- 真实持仓截图（股数 / 成本 / 现价 / 浮盈）
- 分红到账记录（尤其港股通，涉及税后口径）
- 券商 APP 的估值分位（或让项目里的数据模块现算）

这一步是今天神华演练的**破局关键**：一张账户截图，直接校正了「空仓等回调」的错误认知。

### 第 4 步：目标定死（逼用户做二选一）

把模糊的目标逼成明确的对立选项，用户只能选一边：

- 现金流最大化 vs 本金安全
- 追求成长 vs 追求收息
- 一次性决策 vs 持续再平衡

> 目标不定死，后面所有「换不换、买不买、怎么调」都是拍脑袋。

### 第 5 步：落纪律 + 挂提醒（把结论变成可执行规则）

演练的终点不是「结论」，是**一条能自动运行的规则**。产出三样：

1. **写进日记**：定位 / 操作 / 决策心理 / 待想清的追问，落到 `journal/{code}/{YYYY-MM}.md`
2. **变成纪律**：量化触发条件 + 再平衡规则 + 行业上限，写成可机械执行的条款
3. **挂 automation**：到点自动提醒核对（如季度再平衡、月度验证点）

---

## 三、AI 的角色边界（重要）

| 该做的 | 不该做的 |
|--------|---------|
| 主动抛结构化问题 | 替用户下结论 |
| 逼问矛盾、戳逻辑漏洞 | 给精确买卖点位 |
| 算账、拉数据、做场景测算 | 荐股、预测涨跌 |
| 把结论落成纪律 + 提醒 | 把「AI 建议」伪装成「用户决策」 |

- 所有 AI 输出标注「AI 生成 · 非本人操作 · 非荐股」
- 最终决策权永远在潇姐，AI 只负责「把球踢到该踢的位置」

## 四、产物落点

| 产物 | 位置 | 说明 |
|------|------|------|
| 单标的决策 | `journal/{code}/{YYYY-MM}.md` | 定位/操作/决策心理/追问 |
| 组合层分析 | `journal/_组合/账户①-*.md` | 持仓快照/加权股息率/再平衡 |
| 再平衡纪律 | 同上 + automation | 季度触发、自动核对 |

## 五、实战案例（神华 2026-09-03，作为范本）

完整走了一遍五步，结论回顾：

1. **三问**：定位=高股息攒息账户；动作=无持仓观望；心理价=PE/PB 40% 分位以下 + 股息率 6%
2. **逼问**：三个锚其实是同一个价（6% 股息率 ≈ PE12.6 ≈ 31.6 元）；锚应改成「每股分红绝对额」而非浮动股息率
3. **复核**：账户截图揭示——早就在收租（交行+151% / 建行H+516% / 格力+1.3%），加权税后股息率 4.75% 而非以为的 6%
4. **定死**：账户① 第一目标 = 本金安全 + 慢慢收息
5. **落纪律**：神华降级备用候选；账户① 行业上限 50% 纪律式再平衡；季度 automation 已挂

最终结论：**神华从「主决策标的」降级为「备用候选」，本轮不操作**——这是个和用户最初直觉相反、但更正确的结论。
