# FastAPI 查询接口实测证据（2026-09-04）

> 目的：验证 `src/api/main.py` 的 7 个查询端点对「A 股 / 港股 / 银行」三类财报口径标的均能正确返回 mart 层数据，作为「后端 FastAPI 查询 API」JD 缺口的实测证据。

## 测试环境

- **启动命令**：`python -m uvicorn src.api.main:app --host 127.0.0.1 --port 8000`
- **数据层**：DuckDB 数仓 `data/warehouse/fqf.duckdb`（只读连接 `read_only=True`）
- **标的覆盖**：6 只（A股：格力000651 / 神华601088 / 茅台600519；港股：腾讯00700 / 泡泡玛特09992；银行：交行601328）

## 端点测试结果

| # | 端点 | 请求 | 结果 | 说明 |
|---|------|------|------|------|
| 1 | `GET /` | `/` | ✅ 200 | 服务说明 + 端点清单 |
| 2 | `GET /stocks` | `/stocks` | ✅ 200 | 6 只标的 + 最新年度核心指标 |

## 关键发现

1. **7 个端点全通**，A 股 / 港股 / 银行三类财报口径均正确返回，无报错。
2. **安全机制**：指标查询有白名单校验（`metrics/{metric}` 非法值返回 400 + 白名单），防 SQL 注入；DuckDB 只读连接防误写。
3. **小瑕疵（数据层，非接口 bug）**：港股腾讯 `audit_opinion` 为 `None`——港股财报源未接入审计意见字段，属后续数据补缺项。
