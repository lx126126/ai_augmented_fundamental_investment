# 手机网页版部署（伪小程序）

> 目标：把 ValueLine 一页报告变成**手机浏览器直接打开、上下滑动浏览**的体验，零审核、零备案、零后端。
> 相比微信小程序，这条路不需要后端服务器、域名备案、金融类目审核，先验证「产品有没有用」再决定是否投入小程序。

## 现状

- 单票报告：`reports/{报告期}/{code}.html`，已做移动端响应式适配（`@media (max-width:768px)`）。
- 首页入口：`web/index.html`，列出跟踪池标的，点击进入单票详情。

## 三种部署方式（按成本从低到高）

### 方式 A：本地静态服务器（最快，自己手机看）

手机和电脑连同一 WiFi，用 Python 起一个静态服务器：

```bash
cd 项目根目录
python -m http.server 8000
# 手机浏览器打开 http://<电脑局域网IP>:8000/web/index.html
```

电脑局域网 IP 查询：Windows 用 `ipconfig`，看「无线局域网适配器 WLAN」的 IPv4 地址。

### 方式 B：静态托管（最省心，随时随地看，推荐）

把 `web/` + `reports/` 推到 GitHub，用静态托管服务自动部署：

| 平台 | 特点 | 成本 |
|---|---|---|
| **Cloudflare Pages** | 全球 CDN、国内访问需代理、免费 | 免费 |
| **GitHub Pages** | 免费、但国内访问不稳定 | 免费 |
| **Vercel** | 免费、国内访问不稳定 | 免费 |

> 注意：静态托管意味着把报告公开到公网。虽然报告是「纯客观数据、无操作建议」，但个股数据公开仍需自行判断合规边界。**建议先用方式 A 本地看，验证价值后再决定是否公网托管。**

### 方式 C：内网穿透（自己 + 家人看，不动公网）

用 Cloudflare Tunnel / frp 等内网穿透，把本地 `http.server` 映射到一个临时域名，手机在外网也能访问，但不公开到搜索引擎。

## 首页如何自动更新

`web/index.html` 由 `scripts/build_web_index.py` **动态生成**（扫描 `reports/` 最新报告 + `watchlist` 名称映射），不手写维护。两条 Airflow DAG 都会在报告刷新后自动重生成首页：

1. **财报季 DAG**（`valueline_pipeline`）：`web_index` task 在所有票 build 完成后重生成。
2. **每日行情 DAG**（`market_daily`）：`web_index` task 在估值板块轻量重刷后重生成（首页行情数字保持当日值）。

本地也可手动运行：`python scripts/build_web_index.py`。

## 报告期路由约定

- 报告归档路径 `reports/{报告期}/{code}.html`，报告期由数据推导（如 `2026Q2`）。
- 首页链接指向最新报告期的 HTML；报告期变化时重生成首页即可。
