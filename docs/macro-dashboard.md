## 2. 该补什么（4 个缺失维度）

### 2.1 🔴 汇率与美元 —— 你的清单里一个字都没有

这是**最大的遗漏**。美元是全球风险资产的「总闸门」：

| 指标 | 为什么重要 | 数据 |
|---|---|---|
| 美元指数 DXY | 美元走强 → 全球资金回流美国 → 新兴市场（含 A 股）承压 | 🔴 拿不到，见 §4.3 |
| USD/CNY | 人民币贬值 → 外资流出压力 + 人民币资产吸引力下降 | ✅ `currency_boc_sina` 到 09-22 |
| 美债**实际**利率 | 名义利率 − 通胀预期 = 全球估值锚。实际上行 → 全球杀估值 | ✅ 可算（10Y 国债 − 核心 PCE） |
| USD/JPY | 日元套息交易规模巨大，日元急升 = 全球去杠杆信号 | ✅ `currency_boc_sina(日元)` |

> 一句话：**别的指标告诉你「贵不贵」，美元/实际利率告诉你「钱会不会走」**。

### 2.2 🔴 信用与风险偏好 —— 完全没提

| 指标 | 为什么重要 | 数据 |
|---|---|---|
| **美债 10Y−2Y 利差** | 收益率曲线倒挂是**过去 50 年最可靠的衰退领先指标**（领先 12–18 个月）。当前 **+0.25pct**（已回正） | ✅ 一步到位 |
| VIX / VHSI / QVIX | 恐慌度。VIX 拿不到，但 ✅ **VHSI（恒指波幅，18.27）** + ✅ **50ETF QVIX（13.99）/ 300ETF QVIX（15.94）** 都在 | ✅ |
| 中国信用利差 | 中债 AAA 银行债 − 国债 = 企业融资环境的温度计 | ✅ `bond_china_yield` |
| 两融余额 | A 股杠杆资金情绪。当前 **1.36 万亿** | ✅ 到 09-22 |
| A 股新高新低 | **市场宽度**（多少股票在创新高）。比指数点位更能反映真实赚钱效应 | ✅ 到 09-22 |

### 2.3 🔴 中国特有的三个关键指标

| 指标 | 为什么必看 | 当前值（实测） |
|---|---|---|
| **M1−M2 剪刀差** | 中国市场**最经典**的流动性指标。M1 = 企业活期（随时能动），M2 = M1+定期。**剪刀差收窄/转正 = 资金活化 = 经济回暖** | M1 +4.1% − M2 +7.5% = **−3.4pct** |
| **社融增速** | 中国信用周期的核心。宽信用 → 6–9 个月后经济企稳 | ⚠️ 数据滞后到 2026-04 |
| **房价指数（70 城）** | 中国居民资产负债表的核心。房价跌 → 财富效应负 → 消费疲弱 | ✅ 到 2026-08（北京新房同比 97.7 = 跌 2.3%） |

### 2.4 🔴 **周期定位框架** —— 这才是看板的「结论层」

前三条都是**零件**。没有框架，看板就是一堆数字，看完不知道该怎么办。

**美林时钟**（增长 × 通胀四象限）—— 把上面所有指标压成一个结论：

```
                通胀 ↑                    通胀 ↓
增长 ↑    过热（商品/周期股）        复苏（成长股）
增长 ↓    滞胀（现金/黄金）          衰退（债券/防御股）
```

**它的价值在于「可执行」**：定位到「复苏」→ 该看权益；「滞胀」→ 该看黄金/现金。

> 这也是**小红书内容的最佳素材**——「一张图告诉你现在处在周期的哪个位置」比罗列 20 个指标有传播力得多。

### 2.5 顺手补上的高价值指标（数据都在）

| 指标 | 用途 | 数据 |
|---|---|---|
| **ERP 股权风险溢价** = 1/PE − 10Y国债 | 股债性价比。**比巴菲特指标更可操作**（她要做的是股债配置） | ✅ 可算 |
| **铜金比** | 经济景气的高频市场代理（比 PMI 实时） | ✅ 铜/油/金都有 |
| **外汇储备 + 黄金储备** | 中国 3.44 万亿美元 / 黄金 3500 万盎司（同比 +37.9%）—— 央行购金是这几年最重要的宏观叙事 | ✅ 到 2026-08 |
| **全社会用电量** | 「克强指数」核心，比 GDP 难造假 | ✅ 到 2026-08（+4.3%） |
| **企业景气指数** | 中国企业调查的前瞻指标 | ✅ 2026Q2（109.5） |
| **破净股比例** | 极端底部的经典信号 | 🟡 需再试参数 |

## 3. 两个必须讲清的口径陷阱

### 3.1 🔴 巴菲特指标：跨国不可比，只能自己跟自己比

**定义**：股市总市值 ÷ GDP（巴菲特 2001 年提出，称「衡量估值最好的单一指标」）。

**三个陷阱**：

| 陷阱 | 后果 |
|---|---|
| 用 **GDP 而非 GNP** | 美国企业海外利润不计入美国 GDP → 美股巴菲特指标**系统性偏高** |
| **跨国不可比** | 美股常年 200%+，A 股常年 60–80%。原因是 ① 中国 GDP 增速高（分母大）② A 股证券化率天然低（融资靠银行不靠股市）③ A 股有大量不流通国资股 |
| **阈值是经验的** | 巴菲特说的「70–80% 便宜、100% 以上危险」是基于**美股历史**，套 A 股必然误判 |

✅ **正确用法**：各自算、各自看**历史分位**。展示时必须写明「A 股与美股不可横向比较」。

✅ **更好的替代**：**ERP（股权风险溢价）= 1/PE − 10Y 国债收益率**。可直接比较、直接对应「买股还是买债」的决策。A 股圈说的「格雷厄姆指数」本质就是这个。

### 3.2 GDP 是滞后指标，别让它占主位

| 指标类型 | 例子 | 发布频率 | 看板上的位置 |
|---|---|---|---|
| 领先 | 社融、M1、PMI、两融 | 月 | **主位** |
| 同步 | 工业增加值、用电量、社零 | 月 | 中位 |
| 滞后 | **GDP**、CPI | 季/月 | 辅助位 |

### 4.3 沙箱 vs 用户机器 —— 一个必须澄清的前提

上面「东财被拦」是**沙箱网络策略**导致的（记忆里已知：东财 push2 域名在受限网络下 `RemoteDisconnected`）。

> 🔴 **推论**：`index_global_spot_em`、`stock_zh_a_spot_em`、`forex_spot_em` 在**你自己的 Mac 上很可能正常**。
> 但**不能依赖「也许能用」来设计**——接口在沙箱挂掉意味着它**无法进入自动化链路**（日更是脚本跑的）。
> 建议：**关键指标一律选「双源可用」的接口**，东财源的只做「有则增强」。

## 5. 看板结构设计

### 5.1 五层结构（自上而下 = 从「水位」到「该做什么」）

```
① 一句话定位  ← 美林时钟象限 + 结论（整个看板的灵魂）
─────────────────────────────────────────────
② 全球水位    美元 · 美债实际利率 · 央行政策利率 · 全球股指
③ 估值与位置  全A PE/PB 分位 · 沪深300 PE · 巴菲特指标 · ERP 股债性价比
④ 周期与增长  中国：社融/M1-M2/用电量/景气  |  美国：失业率/PMI（二期）
⑤ 市场与情绪  主要股指 · 铜金比 · 波动率 · 两融 · 北向 · 市场宽度
─────────────────────────────────────────────
底部：数据日期 + 口径说明 + 免责声明
```

### 5.2 每个指标的展示规范（🔴 这是看板成败的关键）

| 规范 | 理由 |
|---|---|
| **必须带历史分位** | 「PE 14.8」没有信息量，「PE 处于近 10 年 62% 分位」才有 |
| **必须带趋势箭头/迷你走势** | 单点数值看不出方向；分位数变化才是信号 |
| **必须标数据日期** | 本次实测里中国宏观到 08、社融到 04、中证估值到 08-27，**混排会误导** |
| 涨跌色用**红涨绿跌** | 中国惯例（项目既有约定） |
| 跨市场不可比的指标**显式标注** | 巴菲特指标、PE 口径（整体法 vs 中位数法） |

### 5.3 页面形态

| 项 | 方案 |
|---|---|
| 文件 | `web/macro.html`（与 `web/index.html` 同版式体系，移动优先 640px） |
| 入口 | 首页顶部加「宏观」按钮（与「横向对比」并列） |
| 服务路由 | `web/server.py` 加 `GET /macro` → 返回该 HTML（同首页写法） |
| 数据层 | `src/macro/` 模块 + `data/macro/*.parquet`（保留历史序列才能算分位） |
| 构建 | `scripts/build_macro.py`（拉数 → 落盘 → 渲染 HTML） |
| 更新 | 建议**周更**（宏观数据多为月度，日更无意义且徒增故障面） |

> 🔴 **一个不能踩的坑**：本项目的产物里，`templates/valueline.html`、`web/index.html`、`web/watchlist.html` 是**跟踪的构建产物**，而 `reports/` 整目录不入库。
> `web/macro.html` 若入库，**日更/周更会让工作区每天变脏**。需要明确取舍（见 §7 决策点 C）。

### 8.2 🔴 相对设计的三处偏离

| # | 设计写的 | 实际做的 | 为什么 |
|---|---|---|---|
| ① | `data/macro/*.parquet` 落地历史序列 | **不落地**，每次构建现拉 | 宏观接口每次回传的就是全量历史（估值类回传近 1 年、国债回传全历史），而**日频序列每天重存一份的收益约等于零**——分位与走势用当次拉到的窗口就够了。代价：⚠️ **没有历史留痕**，接口一旦改口径/改回传窗口，旧值不可回滚（个股链靠 parquet 有留痕，这是宏观链明确放弃的东西）。判定标准也已写进 `derive.pct_rank`：分位是「**本序列回传窗口内**」的分位，不是「近 10 年」 |
| ② | 覆盖 §4.1 的 42 个**接口** | 实现为 **47 个指标** | 设计与实现的计数单位不同：一个接口常产出多个指标（`bond_zh_us_rate` 一个接口出中美国债 + 利差 + 汇率），另有若干**派生指标**（`m1_m2_gap` / `erp_*` / `buffett_cn` / `copper_gold` / `oil_yoy` / `usd_jpy` / `shrzgm` / `house_price_70`）。接口数本身也少于 42（部分接口不可用或降级为派生） |
| ③ | §5.1 的设计是**五层** | 实现为**四个分组**：水位 11 / 估值 9 / 增长 14 / 情绪 13 | 原②③④三层的边界在实际排布中互相咬合（利率既属「水位」也在「股债性价比」里出现），硬分五层会迫使同一个指标在页面上出现两次。改为四组 + 顶部「一句话定位」独立成 hero，信息不减 |

### 8.4 本项目的口径铁律（宏观侧新增三条）

沿用个股链「色阶只表示方向」「跨零点不给百分比」的同一套思路：

1. **变化量有三种口径，不可混用**（`chg_unit`）——收益率用 `bp`（基点，1bp = 0.01%）、本身就是百分比的指标用 `pct`（**百分点差**）、点位/金额/家数用 `%`（相对变化率）。用相对变化率描述 CPI 会得到「+60%」这种荒谬值。
2. **跨零点不给百分比**（`change()` 在两期异号时返回空）—— 由渲染端改述「由负转正」这类中性事实，而不是算出一个分母趋零的离谱数字。
3. **色阶只表示变动方向，不表示利好利空** —— 失业率上行与用电量上行是同一个红色，含义却相反。每条图卡的脚注都印这句。

另有两条与「结论层」绑定的规则：

- **方向是「同比的变化方向」（二阶），不是同比本身的符号** —— CPI 同比 +0.8% 是正通胀，但若上期 +0.5%，则通胀在**回升**。
- **净票为 0 时报「方向分歧」，不硬塞象限、不沉默** —— 2×2 时钟四格整体降透明度（`.q.dim`）表达「未定位」而非「渲染失败」，并列出每一票供复核。**不做资产推荐。**
