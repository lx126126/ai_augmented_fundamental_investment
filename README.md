# AI 增强的基本面投研

为 A 股标的输出 **ValueLine 风格的一页投研报告**，季度更新，后续延伸为小程序产品。代码通过 GitHub 维护。

## 项目目标

| # | 目标 | 说明 |
|---|------|------|
| 1 | ValueLine 一页研报 | 每个标的输出紧凑一页，覆盖定位、财务、估值、逻辑、风险、复盘 |
| 2 | 季度更新机制 | 跟踪池 5-8 只封顶，年报/中报季全量更新，Q1/Q3 按需轻量 |
| 3 | 小程序产品 | 景气度扫描（免费）→ 行业深度（付费）→ 个股一页纸（付费） |

## 四层架构

```
数据层   →  分析层   →  报告层   →  产品层
采集·校验·入库  指标·估值·分类  一页报告·季度更新  小程序·内容分发
─────────────────────────────────────────────────────
        方法论底座：格雷厄姆流派 + 彼得·林奇六类
```

- **数据层**：AKShare（主）+ mootdx/腾讯行情（备用），本地 parquet/sqlite 存储。
- **分析层**：基本面指标计算、估值与历史分位、林奇六类分类 + 格雷厄姆质量体检。
- **报告层**：ValueLine 一页 HTML 模板 + 季度更新引擎 + 跟踪池管理。
- **产品层**：微信小程序 + 内容发布（四大文字形态）+ 后端 API。

## ValueLine 模板 v1.5 字段说明

> **载体形态**：纵向长图（1080px 宽 × 高度自适应），单栏纵向堆叠，适配小程序上下滑动与小红书笔记。

| 模块 | 字段 | 方法论锚点 |
|------|------|-----------|
| 头部 | 公司名 / 代码 / 行业 / 报告期 / 发布日期 | — |
| 分类徽章 | 林奇六类定位 + 格雷厄姆质量评级 | 方法论底座 |
| 一句话定位 | 主营 + 商业模式 | — |
| 核心财务数据（全历史） | 上市以来逐年表格：利润表 + 资产负债表 + 股本结构（普通股 / 优先股数量）+ 股息率，逐年列（2007 上市至今） | 全周期视角 + 格雷厄姆财务稳健性 |
| 估值与市场 | PE / PB / 股息率 + 历史分位 + 52周高低价区间 + 机构一致目标价 + 评级分布 | 安全边际 + 市场预期 |
| 机构观点分歧 | 看多（红）/ 看空（绿）观点分别列出 | 多空平衡视角 |
| 财务造假检测 | M-Score / 现金流背离 / 应收异常 / 审计意见（算法待打磨） | 财务真实性 |
| 格雷厄姆体检 | 负债率 / 流动比率 / 盈利稳定性 / 净现金 + 综合评分 | 格雷厄姆流派 |
| 投资逻辑 | 3-5 条论点 | 格雷厄姆 + 林奇 |
| 风险提示 | 3-4 条 | — |
| 季度复盘 | 上季假设 → 实际 → 验证 ✓ / 打脸 ✗ | **系列灵魂** |
| 数据校验 | 来源 / 口径 / 校验日期 / 校验人 | 护城河 |

> 模板由 `scripts/build_valueline.py` 生成（内含示例数据 + 逐年表格渲染），未来数据绑定即复用此脚本替换数据源。52周价格、机构目标价与多空观点均标注为第三方机构观点，非本人建议。

## 快速上手

```bash
# 预览模板
# 直接用浏览器打开 templates/valueline.html

# 导出 PNG 长图 + PDF（首次需装 playwright）
pip install playwright && playwright install chromium
python scripts/export.py templates/valueline.html -o reports/2026Q2 -f png pdf
# PNG 为 @2x 超清长图（2160px 宽），可直接用于小程序/小红书
```

## 铁律（合规）

- **公开版完全去操作**：不出现价格点位、仓位、目标价、买卖建议。
- 操作层（敢接价 / 挂单）只进内部投研日记，不进公开产物。
- 每页附免责声明：仅供研究记录，不构成投资建议。
- 数据需逐项校验，来源留痕（数据校验记录模块）。
