# ---------- 注意：jsonpath 只有源码包，pip 直接装会失败 ----------
# akshare 依赖 jsonpath，而 jsonpath 在 PyPI 上只发布 sdist（jsonpath==0.82.2）。
# 直接 `pip install akshare` 时，pip 会在「下载并解包」环节稳定报：
#   OSError: EEXIST: file already exists, mkdir '.../pip-install-xxxx/jsonpath_xxxx'
# 变通做法（已验证）：手工给它打一个 wheel 再装。wheel 规范上就是一个特定结构的 zip：
#   jsonpath.py
#   jsonpath-0.82.2.dist-info/{METADATA,WHEEL,top_level.txt,RECORD}
# 打完 `pip install jsonpath-0.82.2-py3-none-any.whl`，pip 会正常校验 RECORD 并安装。
# 装上之后 jsonpath 这个依赖就被满足了，此时再 `pip install akshare` 即可通过。
# 若将来 pip 修掉了这个 bug，本段可删，直接 pip install -r requirements.txt 即可。
